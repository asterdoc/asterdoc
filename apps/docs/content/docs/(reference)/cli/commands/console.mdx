Opens the Asterdoc web console in your default browser.

## Usage

```bash
asterdoc console
```

## Description

The `console` command provides quick access to the Asterdoc web console at `https://console.asterdoc.com`. When executed, it opens the URL in your default web browser.

## Examples

Open the web console:

```bash
asterdoc console
```

Output:

```
Opening Asterdoc console...
```
