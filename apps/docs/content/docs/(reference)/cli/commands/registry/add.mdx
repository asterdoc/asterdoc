Add or update a registry configuration.

## Usage

```bash
asterdoc registry add <url> [options]
asterdoc registry add <namespace> <url> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `first` | Registry namespace (e.g., `@acme`), or the registry URL when it is the only argument |
| `second` | Registry base URL (required when the first argument is a namespace) |

## Options

| Option | Description |
|--------|-------------|
| `--header <header>` | Add HTTP header (format: "Name: Value"). Can be used multiple times. |
| `--global` | Save to global config (~/.asterdoc/config.json) |
| `--project` | Save to project config (asterdoc.json) |
| `-y, --yes` | Skip confirmation prompts. Uses the registry's suggested namespace and overwrites an existing namespace |

## Description

Adds a registry to your configuration. The `@` prefix on the namespace is optional.

Any namespace can be added except `@asterdoc`. It is reserved for the Asterdoc registry, which is not available yet, so `asterdoc registry add @asterdoc <url>` is refused. See [Namespaces](/concepts/registries#namespaces).

With a URL alone, the CLI fetches the registry's `registry.json` and suggests `@<name>` as the namespace. You confirm or change it at the prompt, or `--yes` accepts it.

If the namespace already exists, you are asked to overwrite it, pick a different name, or cancel. `--yes` overwrites.

Passing both `--global` and `--project` is an error. If neither is specified, the CLI prompts for a scope unless `--yes` is set. With `--yes`, it uses project config inside a project and global config elsewhere.

## Examples

Add a public registry:

```bash
asterdoc registry add @acme https://registry.acme.com
```

Add by URL and take the namespace from the registry:

```bash
asterdoc registry add https://registry.acme.com --yes
```

Add with authentication:

```bash
asterdoc registry add @private https://registry.example.com \
  --header 'Authorization: Bearer ${REGISTRY_TOKEN}'
```

Single quotes keep the placeholder in the saved config. The CLI expands it from the environment when making a request.

Add to global config:

```bash
asterdoc registry add @company https://registry.company.com --global
```
