Show detailed information about a registry.

## Usage

```bash
asterdoc registry info <namespace> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `namespace` | Registry namespace |

## Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

## Output

```
acme

Official forms and documents for Acme Corp

URL: https://registry.acme.com
Homepage: https://acme.com/forms
Artifacts: 7
Editions: 2
Releases: 11

By kind:
  form: 6
  checklist: 1
```

`Editions` counts the editions of every artifact that has them. `Releases` counts every version of every edition, and every version of each artifact that has no editions.
