Shows detailed information about an installed artifact.

## Usage

```bash
asterdoc registry view <artifact> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `artifact` | Installed artifact, in `@namespace/name` format |

## Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

## Description

Displays comprehensive information about an installed artifact, including:

- The installed edition, when the artifact has one
- Version and kind
- Title and description
- Installation timestamp
- File path and source URL
- Downloaded and available layers

## Examples

View an artifact:

```bash
asterdoc registry view @acme/residential-lease
```

Output as JSON:

```bash
asterdoc registry view @acme/residential-lease --json
```

## Output

```
@acme/residential-lease

Version: 1.0.0
Kind: form
Title: Residential Lease Agreement
Description: Standard residential lease agreement

Installed: 1/15/2025, 10:30:00 AM
Output: yaml
Path: artifacts/@acme/residential-lease.yaml
Source: https://registry.acme.com/residential-lease/1.0.0/residential-lease.json

Layers:
  pdf: residential-lease.pdf
  markdown: residential-lease.md

Available layers (not installed): html
```

An artifact that has editions also shows the installed edition:

```
@acme/w4

Edition: 2025
Version: 1.0.0
Kind: form
Title: Employee's Withholding Certificate

Installed: 1/15/2025, 10:30:00 AM
Output: json
Path: artifacts/@acme/w4.json
Source: https://registry.acme.com/w4/2025/1.0.0/w4.json
```

## Error handling

If the artifact is not installed:

```
Artifact not installed: @acme/residential-lease
Run 'asterdoc add @acme/residential-lease' to install it.
```
