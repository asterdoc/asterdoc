List all configured registries. The built-in `@asterdoc` registry is not listed, because it is never configured.

## Usage

```bash
asterdoc registry list [options]
asterdoc registry ls [options]
```

## Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

## Output

```
Configured registries (2):

@acme [project]
  https://registry.acme.com

@company [global]
  https://registry.company.com
```
