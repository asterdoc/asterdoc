Manages the registry data cache used to speed up registry operations.

## Usage

```bash
asterdoc cache <command> [options]
```

## Subcommands

| Command | Description |
|---------|-------------|
| `clear` | Clear all cached registry data |
| `stats` | Show cache statistics (alias: `info`) |
| `invalidate` | Invalidate cache for a specific registry |
| `config` | Show current cache configuration |
| `reset` | Reset cache configuration to defaults |

---

## cache clear

Clear all cached registry data.

```bash
asterdoc cache clear
```

### Output

```
✓ Cleared 12 cached entries
```

---

## cache stats

Show cache statistics.

```bash
asterdoc cache stats [options]
```

`asterdoc cache info` is an alias.

### Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

### Output

```
Cache Statistics

Directory: ~/.asterdoc/cache
Default TTL: 1h
Disk entries: 12
Total size: 45.2 KB
```

---

## cache invalidate

Invalidate cache for a specific registry.

```bash
asterdoc cache invalidate <namespace>
```

### Arguments

| Argument | Description |
|----------|-------------|
| `namespace` | Registry namespace to invalidate (e.g., `@acme`) |

### Example

```bash
asterdoc cache invalidate @acme
```

---

## cache config

Show current cache configuration.

```bash
asterdoc cache config [options]
```

### Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |

### Output

```
Cache Configuration

Effective directory: ~/.asterdoc/cache

Global config:
  TTL: 1h

Project config:
  (not configured)
```

---

## cache reset

Reset cache configuration to defaults.

```bash
asterdoc cache reset [options]
```

### Options

| Option | Description |
|--------|-------------|
| `--clear` | Also clear all cached data |

### Output

```
✓ Cache configuration reset to defaults

Default settings:
  TTL: 3600s (1 hour)
  Directory: ~/.asterdoc/cache
```
