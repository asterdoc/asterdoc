Opens the Asterdoc documentation website in your default browser.

## Usage

```bash
asterdoc docs
```

## Description

The `docs` command provides quick access to the Asterdoc documentation. When executed, it opens `https://docs.asterdoc.com` in your default web browser.

## Examples

Open documentation:

```bash
asterdoc docs
```

Output:

```
Opening Asterdoc documentation...
```
