Displays information about Asterdoc CLI.

## Usage

```bash
asterdoc about
```

## Description

The `about` command shows version and environment information for the Asterdoc CLI, including the CLI version, platform, Node.js version, and current working directory.

## Examples

Show about information:

```bash
asterdoc about
```

## Output

```
Asterdoc CLI

Version:        0.7.0
Platform:       darwin
Node Version:   v22.18.0
Working Dir:    /Users/you/my-project
```
