Inspects PDF form fields to aid in bindings configuration.

## Usage

```bash
asterdoc inspect <pdf> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `pdf` | PDF template file (path or `-` for stdin) |

## Options

| Option | Description |
|--------|-------------|
| `--format <format>` | Output format: `table` or `json` (default: table) |
| `--filter <pattern>` | Filter field names by glob pattern (e.g., `party_*`) |
| `--summary` | Show totals only (no field listing) |
| `--include-buttons` | Include button fields in the output |
| `--include-signatures` | Include signature fields in the output |
| `--out <file>` | Write inspection result to JSON file |

## Description

The `inspect` command extracts and displays all AcroForm fields from a PDF file. This helps you understand the PDF's field structure when configuring form bindings.

## Examples

Inspect a PDF:

```bash
asterdoc inspect form-template.pdf
```

Filter fields by pattern:

```bash
asterdoc inspect form-template.pdf --filter "address_*"
```

Output as JSON:

```bash
asterdoc inspect form-template.pdf --format json
```

Get summary only:

```bash
asterdoc inspect form-template.pdf --summary
```

Save to file:

```bash
asterdoc inspect form-template.pdf --out fields.json
```

## Output

Table format:

```
Fields from /Users/you/my-project/form-template.pdf:
┌──────────────────┬──────────┬──────────┬────────────┬─────────┐
│ Name             │ Type     │ Required │ Multi-line │ Value   │
├──────────────────┼──────────┼──────────┼────────────┼─────────┤
│ full_name        │ text     │ yes      │ no         │         │
│ address_lines    │ text     │ yes      │ yes        │         │
│ address_city     │ text     │ yes      │ no         │         │
│ agree_terms      │ checkbox │ no       │            │ false   │
└──────────────────┴──────────┴──────────┴────────────┴─────────┘
```

`Multi-line` is `yes` or `no` for a text field and empty for any other field. In `--format json`, a text field has a `multiline` boolean. A [binding template](/guides/pdf-layers#several-values-in-one-field) may hold a line break only for a multi-line field; a single-line field prints it as a space, and `asterdoc validate` reports an error.

For a dropdown, a list box or a radio group, the command lists the options under the table: the value the PDF stores, then the text it shows when the two differ. A list that repeats is printed once.

```
Options (the value the PDF stores = the text it shows):
  status:
    "F1" = F1 - STUDENT - ACADEMIC
    "B2" = B2 - VISITOR FOR PLEASURE
  prior_status: the same as status
  filing:
    "single"
    "joint"
```

In `--format json`, such a field has `options`, an array of `{ value, label }`. A fill writes the value it is given into the field, so the `value` of each option of the bound enum field must be the stored value, not the shown text.

Summary format:

```json
{
  "source": "/Users/you/my-project/form-template.pdf",
  "total": 15,
  "breakdown": {
    "text": 10,
    "checkbox": 3,
    "dropdown": 2
  }
}
```
