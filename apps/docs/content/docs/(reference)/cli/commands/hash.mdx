Compute a SHA256 checksum of a file, formatted for use in layer definitions.

## Usage

```bash
asterdoc hash <file> [options]
```

## Arguments

| Argument | Description |
|----------|-------------|
| `file` | File to compute hash for, or `-` for stdin |

## Options

| Option | Description |
|--------|-------------|
| `--json` | Output as JSON |
| `-a, --algorithm <algorithm>` | Hash algorithm (default: `sha256`) |

## Description

Computes the SHA256 checksum of a file and outputs it in the `sha256:<hex>` format used by Asterdoc layer definitions. This is useful when manually adding file-backed layers to artifacts.

## Examples

Hash a PDF file:

```bash
asterdoc hash lease-template.pdf
```

Output:

```
sha256:a3f2b8c4e5d6...
```

JSON output:

```bash
asterdoc hash lease-template.pdf --json
```

```json
{
  "checksum": "sha256:a3f2b8c4e5d6...",
  "algorithm": "sha256",
  "hash": "a3f2b8c4e5d6...",
  "path": "/Users/you/my-project/lease-template.pdf"
}
```

Hash from stdin:

```bash
cat file.pdf | asterdoc hash -
```
