Reset the Asterdoc CLI to factory defaults.

## Usage

```bash
asterdoc reset [options]
```

## Options

| Option | Description |
|--------|-------------|
| `-y, --yes` | Skip confirmation prompt |
| `--keep-registries` | Keep registry configurations |
| `--keep-cache` | Keep cached data |

## Description

Performs a factory reset of the CLI by:

1. Clearing the registry cache (`~/.asterdoc/cache`)
2. Creating a fresh default configuration (`~/.asterdoc/config.json`)

You will be prompted for confirmation unless `--yes` is passed.

## Examples

Full reset:

```bash
asterdoc reset -y
```

Reset but keep registries:

```bash
asterdoc reset --keep-registries
```

Reset but keep cache:

```bash
asterdoc reset --keep-cache
```
