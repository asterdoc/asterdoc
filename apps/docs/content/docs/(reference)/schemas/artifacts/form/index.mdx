---
title: Form Schema
description: An artifact for dynamic documents with fields, annexes, and parties
---

A Form is the workhorse of Asterdoc. It defines dynamic documents that can be populated at runtime with:
- data fields
- parties (including roles and signature/witness requirements)
- annexes (attachments that can be appended at runtime)

It can be used to create a simple consent form with a few fields to complex forms with multiple nested fields, annexes, signatory requirements, and conditional rendering logic.

## Test cases

Each test case applies its `input` to an empty draft through `update()`, so masks, countries and regions are canonicalized as for any input. It then validates the draft and compares the outcome with `expect`.

<PropertiesTable properties={[
  { name: 'name', type: 'string', description: 'Name of the test case, unique within the form' },
  { name: 'input', type: '{ fields?, parties?, annexes? }', description: 'The values applied to an empty draft through update()' },
  { name: 'context', type: '{ asOf?: string }', description: 'asOf is the instant today() and now() read, an ISO 8601 instant with an explicit timezone. Without it, they read the current instant', isOptional: true },
  { name: 'expect.valid', type: 'boolean', description: 'Whether the draft is valid: the input is accepted, no value is missing or invalid, and every error-severity rule passes. An input update() refuses makes the draft invalid with no rule failures' },
  { name: 'expect.failures', type: 'string[]', description: 'The ids of every rule that fails, warnings included, in any order. Each must name a rule. Omitted, failed rules are not compared', isOptional: true },
]} />

Test cases ship inside the published artifact. Use synthetic values only. `asterdoc validate` warns when a test case sets a `sensitive` field.

```yaml
tests:
  - name: a short account number fails
    input:
      fields:
        startDate: '2026-12-01'
        account: '000000000001'
    context:
      asOf: '2026-11-10T00:00:00Z'
    expect:
      valid: false
      failures: [accountLength]
```

## Form Components

| Component                                              | Description                                    |
| ------------------------------------------------------ | ---------------------------------------------- |
| [FormField](/schemas/artifacts/form/field)             | Field definitions for capturing user input     |
| [FormAnnex](/schemas/artifacts/form/annex)             | Attachment slot definitions                    |
| [FormParty](/schemas/artifacts/form/party)             | Party role definitions with signature requirements |

## Examples

```yaml tab="YAML"
$schema: https://schema.asterdoc.com/__SCHEMA_VERSION__.json
kind: form
name: lease-agreement
version: "1.0.0"
title: Residential Lease Agreement
description: Standard residential lease agreement

defs:
  hasPets:
    type: boolean
    value: "fields.petsAllowed == true"

fields:
  propertyAddress:
    type: address
    label: Property Address
    required: true
  monthlyRent:
    type: money
    label: Monthly Rent
    required: true
  leaseStart:
    type: date
    label: Lease Start Date
    required: true
  leaseTerm:
    type: enum
    label: Lease Term
    enum: [{ value: "12 months" }, { value: "24 months" }, { value: "Month-to-month" }]
  petsAllowed:
    type: boolean
    label: Pets Allowed
    default: false
  petDeposit:
    type: money
    label: Pet Deposit
    visible: hasPets
    required: hasPets

parties:
  landlord:
    label: Landlord
    partyType: any
    required: true
    signature:
      required: true
  tenant:
    label: Tenant
    partyType: person
    min: 1
    max: 4  # allows 1-4 tenants (array format)
    required: true
    signature:
      required: true
      witnesses: 1

layers:
  pdf:
    kind: file
    mimeType: application/pdf
    path: /templates/lease-agreement.pdf
    bindings:
      property_address: propertyAddress
      monthly_rent: monthlyRent
  html:
    kind: file
    mimeType: text/html
    path: /templates/lease-agreement.html

defaultLayer: pdf

annexes:
  identification:
    title: Tenant Identification
    description: Copy of government-issued ID
    required: true
  proofOfIncome:
    title: Proof of Income
    description: Recent pay stubs or tax returns
    required: false
```
