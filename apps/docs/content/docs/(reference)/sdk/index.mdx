The `@asterdoc/sdk` package is the main framework entry point for creating,
validating, rendering, and sealing Asterdoc artifacts.

The SDK builds artifacts in TypeScript. For the JSON shape of the same artifacts, see the [schema reference](/schemas).

## What the SDK includes

`@asterdoc/sdk` re-exports four packages, so one import covers the common path:

| Package | Description |
|---------|-------------|
| [`@asterdoc/core`](/sdk/artifacts) | Builders, instances, lifecycle types, bundle assembly, and sealing for every artifact type |
| [`@asterdoc/format`](/sdk/formatting) | Locale-aware presentation of artifact values |
| [`@asterdoc/sessions`](/sdk/sessions) | Event-sourced form-completion sessions |
| [`@asterdoc/render`](/sdk/renderers) | The MIME-selected `createLayerRenderer()` entry point, plus the PDF placement helpers `locate`, `locator`, and `extractFieldsFromPdf` |

The SDK also exports `hostedSealAdapter`, which converts non-PDF layers through the hosted converter when you seal.

Install `@asterdoc/render` directly when you import its format subpaths
(`@asterdoc/render/text`, `/pdf`, `/docx`) or want rendering as an explicit
dependency.

## Related packages

These packages are not part of `@asterdoc/sdk`. Install each one on its own.

| Package | Description |
|---------|-------------|
| [`@asterdoc/resolvers`](/sdk/resolvers) | Read file-backed layers from the filesystem (`/fs`), over HTTP (`/http`), or from memory (`/memory`) |
| [`@asterdoc/expr`](/sdk/expr) | The expression language behind artifact logic |
| [`@asterdoc/react`](/sdk/react) | React bindings, pagination, and the runtime for React layers |
| [`@asterdoc/react-pdf`](/sdk/react-pdf) | PDF rendering and composition checks for `@asterdoc/react` |
| [`@asterdoc/essentials`](/sdk/essentials) | Ready-to-use artifacts for common business forms |
| [`@asterdoc/ai-tools`](/ai-tools/api) | Framework-neutral AI tool definitions |
| [`@asterdoc/ai-sdk`](/ai-tools/adapters#asterdocai-sdk) | Adapter for the Vercel AI SDK |
| [`@asterdoc/tanstack-ai`](/ai-tools/adapters#asterdoctanstack-ai) | Adapter for TanStack AI |
| [`@asterdoc/mastra`](/ai-tools/adapters#asterdocmastra) | Adapter for Mastra |
