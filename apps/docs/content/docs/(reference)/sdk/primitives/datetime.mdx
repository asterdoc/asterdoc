Validate datetime strings in ISO 8601 format. The Datetime primitive ensures timestamps are properly formatted with date, time, and timezone information.

## Examples

### Creating datetimes

```ts
// Direct validation
const dt = a.datetime('2024-01-15T10:30:00Z')

// Parse unknown input
const dt = a.datetime.parse(jsonData)

// Get current datetime
const now = a.datetime.now()

// Convert from Date object
const dt = a.datetime.fromDate(new Date())

// Check validity without throwing
if (a.datetime.isValid('2024-01-15T10:30:00Z')) {
  console.log('Valid datetime')
}
```

### Parsing external data

```ts
// Parse unknown input (throws on error)
const dt = a.datetime.parse(userInput)

// Safe parsing (returns result object)
const result = a.datetime.safeParse(userInput)
if (result.success) {
  console.log(`Datetime: ${result.data}`)
} else {
  console.error(result.error.message)
}
```

### Using with forms

```ts
const form = a.form({
  name: 'appointment',
  fields: {
    scheduledAt: { type: 'datetime', label: 'Appointment Time' }
  }
})

const filled = form.fill({
  fields: {
    scheduledAt: a.datetime('2024-06-15T14:30:00Z')
  }
})
```

## API

### Direct Call

```ts
a.datetime(input: string): string
```

Pass a datetime string for validation. Returns the validated string or throws on error.

```ts
const dt = a.datetime('2024-01-15T10:30:00Z')
```

## Format

The Datetime primitive expects and returns strings in ISO 8601 datetime format:

```
YYYY-MM-DDTHH:mm:ssZ
YYYY-MM-DDTHH:mm:ss[.fraction]Z
YYYY-MM-DDTHH:mm:ss±HH:mm
```

| Component | Description | Example |
|-----------|-------------|---------|
| `YYYY-MM-DD` | Date portion | 2024-01-15 |
| `T` | Separator | T |
| `HH:mm:ss` | Time (24-hour) | 10:30:00 |
| `.fraction` | Fractional seconds, one or more digits (optional) | .123 |
| `Z` | UTC timezone | Z |
| `±HH:mm` | Timezone offset | +05:30 |

## Validation

The Datetime primitive validates:

- String must be a valid ISO 8601 datetime format
- Date portion must be valid (see [date](/sdk/primitives/date))
- Time portion must be valid (see [time](/sdk/primitives/time))
- Timezone must be specified (Z or offset)

```ts
// Valid
a.datetime('2024-01-15T10:30:00Z')
a.datetime('2024-01-15T10:30:00.123Z')
a.datetime('2024-01-15T10:30:00+05:30')
a.datetime('2024-01-15T10:30:00-08:00')

// Invalid - throws Error
a.datetime('2024-01-15')

a.datetime('2024-01-15T10:30:00')

a.datetime('2024-01-15 10:30:00Z')

a.datetime('not-a-datetime')
```
