<Step>
## Define the Form

A form needs a name, fields, and parties. Here's a simple lease agreement:

```ts tab="Object Pattern"
import { a } from '@asterdoc/sdk'

const lease = a.form({
  name: 'lease-agreement',
  version: '1.0.0',
  title: 'Residential Lease Agreement',
  parties: {
    landlord: { label: 'Landlord', partyType: 'person', signature: { required: true } },
    tenant: { label: 'Tenant', partyType: 'person', signature: { required: true } },
  },
  fields: {
    address: { type: 'address', label: 'Property Address', required: true },
    monthlyRent: { type: 'money', label: 'Monthly Rent', required: true },
    startDate: { type: 'date', label: 'Start Date', required: true },
    endDate: { type: 'date', label: 'End Date', required: true },
  },
})
```

```ts tab="Builder Pattern"
import { a } from '@asterdoc/sdk'

const lease = a
  .form()
  .name('lease-agreement')
  .version('1.0.0')
  .title('Residential Lease Agreement')
  .parties({
    landlord: a.party().label('Landlord').partyType('person').signature({ required: true }),
    tenant: a.party().label('Tenant').partyType('person').signature({ required: true }),
  })
  .fields({
    address: a.field.address().label('Property Address').required(),
    monthlyRent: a.field.money().label('Monthly Rent').required(),
    startDate: a.field.date().label('Start Date').required(),
    endDate: a.field.date().label('End Date').required(),
  })
  .build()
```
</Step>

<Step>
## Add a Layer

Templates define how forms render. Add an inline Markdown template using
Asterdoc's deterministic template syntax:

```ts tab="Object Pattern"
const lease = a.form({
  name: 'lease-agreement',
  // ...fields and parties
  defaultLayer: 'markdown',
  layers: {
    markdown: {
      kind: 'inline',
      mimeType: 'text/markdown',
      text: `
# Residential Lease Agreement

**Property:** {{fields.address}}
**Monthly Rent:** {{fields.monthlyRent}}
**Term:** {{fields.startDate}} to {{fields.endDate}}

**Landlord:** {{parties.landlord.name}}
**Tenant:** {{parties.tenant.name}}
      `,
    },
  },
})
```

```ts tab="Builder Pattern"
const lease = a
  .form()
  .name('lease-agreement')
  // ...fields and parties
  .defaultLayer('markdown')
  .layers({
    markdown: a.layer.inline().mimeType('text/markdown').text(`
# Residential Lease Agreement

**Property:** {{fields.address}}
**Monthly Rent:** {{fields.monthlyRent}}
**Term:** {{fields.startDate}} to {{fields.endDate}}

**Landlord:** {{parties.landlord.name}}
**Tenant:** {{parties.tenant.name}}
    `),
  })
  .build()
```
</Step>

<Step>
## Fill the Form

Use `.fill()` to create a runtime instance with data:

```ts
const filled = lease.fill({
  parties: {
    landlord: { id: 'landlord-0', name: 'Jane Smith' },
    tenant: { id: 'tenant-0', name: 'John Doe' },
  },
  fields: {
    address: {
      line1: '123 Main St',
      locality: 'Portland',
      region: 'OR',
      postalCode: '97201',
      country: 'USA',
    },
    monthlyRent: { amount: 1500, currency: 'USD' },
    startDate: '2025-02-01',
    endDate: '2026-01-31',
  },
})
```

Party data requires an `id` field—this is used for signature tracking.
</Step>

<Step>
## Render the Form

Render the filled form. Asterdoc selects the built-in implementation from the
layer's MIME type:

```ts
const output = await filled.render()

console.log(output)
```

Output:

```markdown
# Residential Lease Agreement

**Property:** 123 Main St, Portland, OR 97201, USA
**Monthly Rent:** $1,500.00
**Term:** Feb 1, 2025 to Jan 31, 2026

**Landlord:** Jane Smith
**Tenant:** John Doe
```

Fields are automatically serialized—`money` becomes `$1,500.00`, `address` becomes a formatted string.
</Step>

<Step>
## Save the Artifact

Export the form to JSON or YAML for storage or version control:

```ts
const json = lease.toJSON() // or lease.toYAML()
console.log(JSON.stringify(json, null, 2))
```

```json tab="JSON"
{
  "$schema": "https://schema.asterdoc.com/__SCHEMA_VERSION__.json",
  "kind": "form",
  "name": "lease-agreement",
  "version": "1.0.0",
  "title": "Residential Lease Agreement",
  "fields": {
    "address": { "type": "address", "label": "Property Address", "required": true },
    "monthlyRent": { "type": "money", "label": "Monthly Rent", "required": true },
    "startDate": { "type": "date", "label": "Start Date", "required": true },
    "endDate": { "type": "date", "label": "End Date", "required": true }
  },
  "parties": {
    "landlord": { "label": "Landlord", "signature": { "required": true } },
    "tenant": { "label": "Tenant", "signature": { "required": true } }
  }
}
```

```yaml tab="YAML"
# yaml-language-server: $schema=https://schema.asterdoc.com/__SCHEMA_VERSION__.json
$schema: https://schema.asterdoc.com/__SCHEMA_VERSION__.json
kind: form
name: lease-agreement
version: 1.0.0
title: Residential Lease Agreement
fields:
  address:
    type: address
    label: Property Address
    required: true
  monthlyRent:
    type: money
    label: Monthly Rent
    required: true
  startDate:
    type: date
    label: Start Date
    required: true
  endDate:
    type: date
    label: End Date
    required: true
parties:
  landlord:
    label: Landlord
    partyType: person
    signature:
      required: true
  tenant:
    label: Tenant
    partyType: person
    signature:
      required: true
```

Load it back with `a.load()`:

```ts
const loaded = a.load(jsonString) // works with JSON or YAML
```

`load()` requires the `$schema` that `toJSON()` and `toYAML()` write. A file written for an earlier [schema version](/schemas#loading-rules) fails to load until [`asterdoc migrate`](/cli/commands/migrate) upgrades it.
</Step>
